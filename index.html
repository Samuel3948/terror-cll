1. Propósito del Servicio
Esta herramienta te permite registrar tu dispositivo para que, en caso de pérdida, puedas localizarlo mediante vibración, sonido, bloqueo de pantalla y otras funciones remotas.

2. Datos Recopilados
Proporcionas voluntariamente tu número de teléfono. Este se almacena de forma segura en Firebase y solo el administrador autorizado tiene acceso.

3. Funciones de Localización y Seguridad
Al aceptar, permites que este dispositivo reciba comandos remotos de: vibración, sonido, brillo de pantalla, linterna, voz, GPS, cámara, bloqueo de pantalla y modo pánico.

4. Ubicación
Puedes compartir tu ubicación GPS para facilitar la búsqueda.

5. Seguridad
En caso de pérdida, el administrador puede bloquear la pantalla y activar el modo pánico para proteger tus datos.
